# P0：离线工作区

记录日期：2026-11-13。此阶段完成 `.peek` 文件查看，设备连接与日志同步随后在 P1 接入。当前容量和使用方法见[文件说明](文件与恢复.md)。

## 完成内容

- 固定上游 9 个会话、20 个远程帧样例及 MIT 许可，建立格式兼容测试
- Rust 会话解析、原文保存、窗口查询及容量检查
- 原生打开/保存、后台导入、进度与取消、临时文件原子替换
- 可调整三栏、虚拟表格、搜索过滤、按需详情、JSON Worker 与无损数字
- 中英文、主题、快捷键和布局偏好

## 验证

当时通过 TypeScript、7 项前端测试、9 项 Rust 测试、Rust 格式、Clippy、前端构建及 macOS debug `.app` 构建。

macOS 原生打开官方 `basic.peek` 得到 18 条请求，错误过滤为 6 条。Cmd S 保存后与输入逐字节一致，共 20,340 字节；重复 Set-Cookie 保留两行，JSON 支持非 ASCII 文本。

100,000 条合成会话导入后跳过 0 条，AX 树约显示 33 行；End 到末条、Home 回首条及两端详情正常。JSON 树显示长整数 `900719925474099312345` 和小数 `0.12345678901234567890`。

## 单次核心探针

环境为 Apple M3 Pro、18 GiB RAM、macOS 27.2.1（26B131）、WebKit 22625 / 22625.2.8.11.9、Rust 1.91.1、Node 25.9.0、pnpm 10.33.0，debug 构建。

| 项目 | 结果 |
| --- | --- |
| 输入 | 100,000 条，39,999,203 文件字节，39,899,202 原文字节 |
| 核心导入 | 4,157.09 ms |
| `records/99` 的 20 次窗口查询 | P50 33.67 ms，P95 45.78 ms |

该探针不测 WebView 帧率、实时吞吐、IPC 延迟或进程峰值内存。复现命令见[开发指南](../CONTRIBUTING.md#合成数据与性能探针)。

当时离线库限制为 4 个会话 / 128 MiB；P3 调整为 12 个 / 192 MiB。JSON 编辑器约 1 MiB 的懒加载 chunk 提示仍保留在[待办](待办.md)。
