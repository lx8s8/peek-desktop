# P3：会话归档、导出与恢复

记录日期：2026-11-16。使用步骤和容量见[文件、导出与恢复](文件与恢复.md)，这里保留实现及验收结果。

## 完成内容

| 部分 | 实现 |
| --- | --- |
| `.peekbundle` | ZIP manifest、版本、成员校验和、展开容量、原子保存及整组导入 |
| 历史日志 | 诊断 v1 JSONL 导入为独立离线运行 |
| 导出 | HAR、全部日志 JSONL/文本、当前请求 POSIX cURL；所选 JSONL 保留 |
| 恢复 | 默认关闭、5 秒检查变化、正常退出补存、双份轮换和损坏回退 |
| 并发 | 快照短锁捕获、锁外编解码、整组提交及单写入者文件锁 |

归档保留原文、来源、网络关联、确认位置、缺口和淘汰计数。导入生成独立离线身份，不与实时握手或 ACK 混用。配对凭据不入归档。

## 自动化验证

当时通过 37 项前端测试、43 项常规 Rust 测试、扩展跨语言回归、格式、Clippy 及构建。另有两个恢复子进程辅助用例由父测试显式驱动。

| 范围 | 核对内容 |
| --- | --- |
| 归档 | 原文、长数字、重复 key、原始堆栈、关联和计数往返；重复导入独立身份 |
| 错误处理 | 坏成员、非法路径、未来版本、容量不足整组拒绝；取消及保存失败不破坏旧目标 |
| 导出 | 350 条日志完整导出和回读；HAR 重复头、二进制、正文缺失及耗时算式 |
| cURL | 用本地 shell 参数捕获检查引号、换行、美元符号和反引号转义，不发送请求 |
| 恢复 | 默认关闭、待恢复/空工作区不覆盖、重复恢复阻断、最新损坏回退、双份损坏保留当前数据 |
| 快照 | 文件锁、临时文件清理、未变化不写入、失败保留旧文件、捕获后释放数据锁 |

`recovery_process` 父测试启动两个独立进程：写入进程保存后退出，读取进程重新加载并恢复离线数据。网络 `.peek` 与 JSONL 原文逐字节一致，18 条 HAR 和 cURL 生成通过。

跨语言回归从真实官方客户端取得大正文、长整数/小数和 4 条诊断，经过归档及两份快照恢复后保持原文和准确关联。恢复端不启动监听。

## 单次大数据探针

环境为 Apple M3 Pro、18 GiB RAM、macOS 27.2.1（26B131）、arm64、Rust 1.91.1，debug 构建，100,000 条合成请求。

| 项目 | 结果 |
| --- | --- |
| 输入原文 | 39,899,202 字节 |
| 归档 / HAR | 1,526,361 / 110,589,086 字节 |
| 导入 | 3,321.64 ms |
| 归档保存 / 回读 | 4,195.01 / 4,227.76 ms |
| HAR 导出 | 16,634.68 ms |
| 恢复回读 | 3,920.44 ms |
| 探针总耗时 | 37.17 秒 |
| maximum resident set size | 274,120,704 字节 |
| peak memory footprint | 338,396,000 字节 |

内存由 `/usr/bin/time -l` 记录，包含探针同时持有的输入、归档和恢复对象，不包含 WebView。此结果不代表桌面总内存、实时吞吐或 release 性能。复现见[开发指南](../CONTRIBUTING.md#合成数据与性能探针)。

## macOS 导出与重启验收

原生 debug 应用导入独立 Python 生成的 v1 归档，显示 1 条网络、3 条异常和离线来源；日志、异常、时间线及丢弃/淘汰计数可见，监听关闭。

使用原生保存对话框导出 `.peekbundle`、HAR、全部日志 JSONL 和文本。仓库外临时文件经过独立校验：

- 归档成员 SHA-256、字节数、网络/诊断原文、绑定和来源一致
- HAR 保留重复查询参数、同名响应头和完整长整数、小数
- JSONL 与三条异常输入逐字节一致，文本包含三份完整双行堆栈
- 原生 cURL 复制后核对 URL、方法和 Header，没有执行请求
- 导出 JSONL 重新导入为独立历史运行，与归档绑定日志并存

随后开启自动快照并显式保存，经应用菜单退出，确认旧进程结束后重新启动同一 `.app`。启动为零会话、监听关闭，提示旧快照待恢复；恢复后得到两个网络会话共 7 条请求，以及绑定和独立的两份三条诊断运行。

恢复后核对离线来源、保留计数、三次异常分组、原始 eventId/runId、双行堆栈、`900719925474099312345` 和 `0.12345678901234567890`。第三条异常可跳到准确请求，恢复按钮不再可用。最后把自动快照恢复为验收前的关闭设置，保留离线会话，监听保持关闭。
