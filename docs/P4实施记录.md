# P4：桌面交付

## 图标与打包元数据

应用图标使用仓库内的原创 SVG，生成 macOS ICNS、Windows ICO 和 PNG。`pnpm icons:generate` 通过锁定版本的 Tauri CLI 生成，只保留桌面资源。

应用发布者使用 `kasen`。macOS 配置 `.app` / DMG、最低版本 11.0 及 hardened runtime；Windows 使用当前用户 NSIS 安装，提供简体中文和英文，阻止版本降级。macOS 增加局域网用途和 Bonjour 服务说明。

验证：图标预览、PNG 尺寸和 ICNS/ICO 文件头检查通过；平台配置使用当前 Tauri schema 校验。安装与签名验证随后记录。

## 文件关联与单实例

保留 `local.peek.desktop` 作为稳定应用标识，避免变更已有工作区目录和配对服务。注册 `.peek` 查看和 `.peekbundle` 归档类型；通用 JSONL 继续从打开对话框或显式文件参数导入，不注册系统默认关联。

macOS 接收系统文件 URL；Windows 接收首次启动参数，并通过单实例插件把后续打开请求转交现有窗口。原生队列最多 32 个路径，去重待处理项，溢出后提示。前端先订阅再检查冷启动队列，导入和保存期间等待；逐个复用原有校验、进度和取消逻辑，坏文件不阻断其余文件。取消时清空尚未处理队列。

验证：40 项前端测试、46 项常规 Rust 测试、TypeScript、Rust 格式及 Clippy 通过；新增回归覆盖中文/空格路径、文件 URL、队列上限、非法文件、冷启动订阅、导入期间新事件和坏文件后的继续导入。空队列不会占用导入状态。原生双击和安装验证在安装包步骤执行。
