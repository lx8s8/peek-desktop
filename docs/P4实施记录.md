# P4：桌面交付

## 图标与打包元数据

应用图标使用仓库内的原创 SVG，生成 macOS ICNS、Windows ICO 和 PNG。`pnpm icons:generate` 通过锁定版本的 Tauri CLI 生成，只保留桌面资源。

应用发布者使用 `kasen`。macOS 配置 `.app` / DMG、最低版本 11.0 及 hardened runtime；Windows 使用当前用户 NSIS 安装，提供简体中文和英文，阻止版本降级。macOS 增加局域网用途和 Bonjour 服务说明。

验证：图标预览、PNG 尺寸和 ICNS/ICO 文件头检查通过；平台配置使用当前 Tauri schema 校验。安装与签名验证随后记录。

## 文件关联与单实例

保留 `local.peek.desktop` 作为稳定应用标识，避免变更已有工作区目录和配对服务。注册 `.peek` 查看和 `.peekbundle` 归档类型；通用 JSONL 继续从打开对话框或显式文件参数导入，不注册系统默认关联。

macOS 接收系统文件 URL；Windows 接收首次启动参数，并通过单实例插件把后续打开请求转交现有窗口。原生队列最多 32 个路径，去重待处理项，溢出后提示。前端先订阅再检查冷启动队列，导入和保存期间等待；逐个复用原有校验、进度和取消逻辑，坏文件不阻断其余文件。取消时清空尚未处理队列。

验证：40 项前端测试、46 项常规 Rust 测试、TypeScript、Rust 格式及 Clippy 通过；新增回归覆盖中文/空格路径、文件 URL、队列上限、非法文件、冷启动订阅、导入期间新事件和坏文件后的继续导入。空队列不会占用导入状态。原生双击和安装验证在安装包步骤执行。

## 安装包与签名流程

增加 `package:local`、`package:development`、`package:signed`，分别用于 ad-hoc/未签名预览、本机明确指定的开发证书和正式分发。正式模式缺少证书、公证配置、干净源码或 Release 模式时停止，不生成冒充正式签名的包。正式 macOS 包验证 Developer ID、应用票据和 DMG 公证；Windows 验证应用及安装器的 Authenticode。

版本检查覆盖 npm、Cargo 和 Tauri。安装包清单包含提交、脏工作区、平台、架构、签名模式及 SHA-256。三平台汇总必须来源和版本一致，校验成功后才允许创建 Release 草稿。

本机 macOS arm64 Release 预览包构建耗时 170.2 秒，通过 `codesign --verify --deep --strict`、实际签名类型、Info.plist 版本/文件关联及 `hdiutil verify`。DMG 只读挂载后复制应用，再验签和检查执行文件、图标、两种文件类型通过。此轮构建使用未提交的打包脚本，清单如实标记 dirty；不作为正式发布包。

6 项发布工具测试通过，覆盖签名配置隔离、缺失分发证书、公证配置、版本不一致及安装包篡改；工作流通过 actionlint。三平台工作流将补充真实 Windows / Intel 构建、Windows 静默安装/卸载和文件关联检查，结果待运行后记录。

本机可用证书只有 Apple Development/Distribution，没有 Developer ID Application。尚未使用现有证书，也未执行对外分发签名或 Apple 公证。用户随后确认桌面仓库沿用 MIT；许可补充见下文。

用户确认桌面沿用 MIT，版权署名使用 kasen，Cargo、npm 和安装包元数据同步许可。安装资源增加 MIT 原文和第三方声明；声明覆盖 468 个组件、291 份去重许可文本，另有三个包仅发布许可标识、作者与来源。上游未附带的许可文本按固定源码提交或包版本保存在 `third-party/`，不改写许可正文。

正式分发证书按用户选择随后配置。本轮提供可验证的预览安装包与严格的正式签名/公证流程，未使用现有业务开发证书，也未执行正式签名或公证。实体 Windows 设备配对、真实移动设备及固定签名后的升级/Keychain 行为仍待专项验收。

加入 MIT、第三方资源和新预览文案后，本机 Release 预览包再次构建通过，用时 142.2 秒；应用包内两份许可文件与仓库原文逐字节一致，签名及 DMG 校验继续通过。最新版工作流也增加了 Windows 安装后的许可资源检查。

后续挂载复验发现：全局 `licenseFile` 会把许可嵌入 DMG 的挂载协议，无交互挂载因此取消。现将许可页限定到 Windows，macOS 仅随应用资源附带原文。平台 schema、重新生成的 DMG 挂载复制、签名与许可资源一致性复验通过；挂载工具同时补充失败原因输出。
