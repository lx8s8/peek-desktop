## 发布方式

按用户当前选择，macOS 固定 ad-hoc、不配置分发证书与公证；Windows 固定不签名。工作流不读取证书 Secrets，Windows 安装测试同时核对安装器和应用的 `NotSigned` 状态。

标签发布须完成两个 macOS 架构和 Windows x64 的检查、构建与安装验证。汇总 job 再核对版本、源码、模式和 SHA-256，上传附件后才公开正式 Release。已有公开版本不覆盖。
