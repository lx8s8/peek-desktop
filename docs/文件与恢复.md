# 文件、导出与恢复

## 保存格式

| 格式 | 保存内容 | 用途 |
| --- | --- | --- |
| `.peek` | 网络记录和已保留正文 | 与标准 Peek 会话格式交换 |
| `.peekbundle` | 当前网络、绑定日志及关联、来源、缺口和淘汰计数；也可保存独立日志运行 | 保存完整排查现场 |
| 诊断 JSONL | 每行一条诊断 v1 事件 | 导入日志历史或继续处理 |
| HAR | 当前网络会话 | 交给其他网络分析工具 |
| 日志文本 | 当前运行的消息与堆栈 | 阅读和分享 |

“打开文件”支持前三种格式。标准 `.peek` 的坏记录行会跳过并计数；归档和诊断 JSONL 先完成校验，任一成员损坏或容量不足时整次导入失败。

## 保存与导出范围

保存归档、导出 HAR 和全部日志使用当前保留的数据，不受列表搜索、分组或时间筛选影响。“导出所选事件”只导出选中日志，最多 300 条。

远端正文需先从设备加载，才能保存在本地文件。尚未取回、设备已丢弃或采集时已截断的内容不能通过导出补齐。HTML、SVG 等响应按数据查看，不执行页面。

`.peek` 导出保留有效记录的未知字段、重复 JSON key 和数字原文，统一使用 LF 换行。空行、坏行和同 ID 的旧版本不导出；重复 ID 使用最后值、保留首次位置。

`.peekbundle` 是 ZIP，包含 manifest、网络 `.peek` 和诊断 `.jsonl`。导入时检查版本、成员名、条数、展开大小和 SHA-256，不解压到文件系统。归档不包含设备配对凭据。

## 正文查看与搜索

响应和请求正文中的有效 JSON 默认以格式化文本显示，可切换原文或树视图。格式化与树使用无损数字解析；重复字段、无效 JSON 保留原文，复制始终使用原文。

“搜索正文”查找当前预览中的字段、值和文本，支持大小写切换、上一处/下一处、Enter/Shift Enter。正文区域聚焦时，Cmd/Ctrl F 定位到正文搜索。树视图中输入关键词会临时切换到格式化文本，清除关键词后返回树视图。

正文搜索在 Worker 中执行，最多定位前 2,000 处匹配，超出时提示缩小关键词范围。它只搜索当前可见正文预览；列表搜索仍查找地址、方法、状态和来源。被设备或预览上限截断的内容不在搜索范围内。

## HAR 与 cURL

HAR 保留重复 Header、查询参数和二进制正文。缺失正文、截断和未知耗时写入 `_peek` / `_peekBody` 扩展字段；未知 HTTP 版本为空字符串，未测可选阶段为 -1，格式要求的阶段用 0 并列入 `unknownTimingFields`。捕获总耗时单独存为 `_peek.durationMs`。

“复制当前请求 cURL”生成适用于 POSIX shell 的命令，不会发送请求。支持完整文本和无文件的 URL 编码表单；二进制、文件上传、未加载或截断正文无法生成完整命令。粘贴执行前应检查请求目标和内容。

## 恢复工作区

1. 打开“导出与恢复”，开启自动恢复快照，或点击“立即保存工作区快照”
2. 自动模式每 5 秒检查数据变化，正常退出时补存
3. 下次启动后，从同一入口选择“恢复上次工作区”
4. 恢复的是离线副本，需要实时数据时再手动启动监听

自动快照默认关闭。设置和两份轮换快照位于应用数据目录的 `recovery/`。检测到旧快照后先暂停覆盖，等待恢复或“开始新的恢复记录”；空工作区不会覆盖最近的非空快照。

最新快照校验失败时尝试另一份。两份均损坏或恢复容量不足时，当前工作区保持原样。另一应用实例持有恢复文件锁时，本实例仍可查看数据，但不能写恢复缓存。

快照只能保存已经收到并保留的数据。最近一个检查周期及尚未加载的正文可能无法恢复；诊断 ACK 仍只表示内存接纳，不是磁盘写入确认。

## 容量

| 项目 | 当前限制 |
| --- | --- |
| 单个 `.peek` | 64 MiB，单行 8 MiB，100,000 个不同请求 ID |
| 离线网络库 | 12 个会话，192 MiB 原文 |
| 实时网络 | 8 个会话，每个 10,000 条 / 8 MiB；重同步 staging 另有同等预算 |
| 诊断 | 8 个运行，每个 2,000 条 / 4 MiB，优先淘汰低级别 |
| 单个归档 | 文件及展开总量最多 256 MiB |
| 恢复快照 | 两份轮换，每份最多 256 MiB；还需满足可恢复到离线库的容量 |
| 选中日志 | 最多 300 条，复制内容最多 1 MiB，超出时可导出文件 |
| 正文预览 | 文本 1 MiB，二进制 Hex 4 KiB；JSON 树另受节点数和深度限制 |

这些是保留原文和预览的限制，进程还需要索引、解析及 WebView 内存。异常分组次数按当前保留数据和筛选条件统计，已淘汰记录不计入。

实现及历史验收见 [P3 记录](P3实施记录.md)，诊断确认规则见[协议](诊断协议v1.md)。
