## 本机验证

TypeScript、50 项前端测试、51 项常规 Rust 测试、Prettier、Rust fmt、Clippy 和发布配置检查通过。另两项 Rust 子进程入口由恢复测试调用；Flutter 外部互通测试未在本轮运行。

macOS arm64 Release 预览包从干净提交构建，用时 136.5 秒，清单 `dirty: false`。DMG 校验、只读挂载、临时目录复制应用、签名验证、文件类型和许可资源原文一致性检查通过。

| 原生窗口检查 | 结果 |
| --- | --- |
| 默认监听范围 | 打开连接页即为“局域网设备”，监听保持关闭 |
| 本机地址 | 未启动监听时显示实际 IP 与端口，与系统网卡查询一致；复制有完成反馈，没有触发钥匙串读取 |
| JSON | 默认显示格式化正文，长整数 `900719925474099312345` 与小数 `0.12345678901234567890` 保持原样 |
| 搜索 | `ready` 同时找到 `ready`、`READY`，显示 `1/2`；Enter 跳到 `2/2`，Cmd F 在正文中选择搜索输入 |
| 字段搜索 | `state` 定位到两处字段；选择其他请求后不带入上一条正文的搜索结果 |
| 图片 | PNG、JPEG、GIF、WebP 均显示 256 × 160 的合成图片，图片与十六进制可切换 |
| 异常数据 | 截断图片、损坏图片显示对应说明和 Hex；带事件属性的 SVG 按文本显示 |
| 语言 | 中文与英文的正文搜索、图片工具栏和提示均可切换 |

验收会话由 `body_preview_fixture` 生成，共 8 条请求，不包含业务数据。验收结束保留中文窗口和 WebP 预览，监听关闭。

## 三平台构建

同一源码的[GitHub Actions](https://github.com/lx8s8/peek-desktop/actions/runs/44005620404)已生成 macOS arm64、macOS x64 和 Windows x64 三个预览安装包。macOS 两种架构完成 DMG 挂载复制、签名与许可资源检查；Windows 完成中文及空格路径安装、文件关联、许可资源及卸载检查。

前端检查任务通过；本轮没有创建或公开 Release。Windows 与 Intel macOS 的原生正文渲染未做交互验收，上面的界面结果来自本机 macOS arm64。
