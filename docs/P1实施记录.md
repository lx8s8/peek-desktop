## 实现约定

- 监听默认关闭，由用户显式启动；支持仅本机与局域网模式，手动地址始终可用，mDNS 可选。
- macOS Keychain / Windows Credential Manager 保存稳定 server identity 与设备 token 的 SHA-256 摘要；普通配置和 UI 不接触长 token。凭据失败不降级为明文或临时授权。
- P1 最多配对 4 个设备，以控制系统凭据条目大小。网络授权和诊断授权分别保存；关闭诊断授权仅断开诊断连接，忘记设备关闭两路。
- 配对码只在可信桌面 UI 展示，网络端在握手中接收；不把 token 放入 URL、能力探测或日志。
- ACK 只确认 Rust 内存会话接纳，不表示磁盘写入；完整持久恢复和 `.peekbundle` 仍属于后续阶段。
- 诊断线上字段、批次与确认规则见 [诊断协议 v1](诊断协议v1.md)。
- 网络侧同时最多 16 个握手/连接、8 个运行会话；每会话 10,000 条/8 MiB 原文预算，重同步 staging 另有同等硬上限。淘汰按最早位置批量执行并计数；正文在途最多 32 个、每连接发送队列 16 个，正文超时 8 秒，HTTP 头最多 8 KiB，单 WebSocket 消息最多 8 MiB。

## 2026-11-13 本机回归

- 前端：TypeScript、11 项 Vitest、Prettier 与 Vite 构建通过，覆盖查询/详情竞态、精度、实时详情刷新/淘汰、配对独立授权、工作区旧快照隔离与 Channel 清理。
- Rust：22 项常规测试通过；包含配对失败回滚、真实 TCP/WebSocket 网络与诊断交互、绑定/撤销、重连旧帧隔离、正文关联、序号去重/缺口、容量淘汰。格式与 Clippy `-D warnings` 通过。正文解析和预览在阻塞任务中运行，避免大正文占用网络执行线程。
- SDK：7 项 Flutter 测试与 `flutter analyze --no-pub` 通过。另有跨语言测试，常规运行明确跳过，显式执行验证官方 PeekRemote 2.1.1 与 Rust 配对、历史/实时更新、凭据重连、诊断绑定、4 条日志累计 ACK、脱敏、原始堆栈以及超过 6 KiB 正文取回和 `.peek` 导出。
- macOS：Tauri debug `.app` 和启用诊断开关的 Flutter 示例均编译通过；实际窗口配对成功，两条 WebSocket 分别显示 connected / ready，生成 5 条合成日志后待发归零、ACK 为 5。关闭诊断后网络继续接收第 2 条请求；重新授予并重试后 ACK 续到 6。
- 实际 WKWebView 响应树完整显示 `900719925474099312345` 和 `0.12345678901234567890`；异常筛选只呈现异常，详情保留 Dart 原始帧。配对成功后四位码消失。桌面重启后监听保持关闭、内存会话清空。
- macOS 初次启动已完成系统凭据读写；本地重新编译后，读取已有 Keychain 条目可能触发系统授权窗口，需用户在本机处理，不能将等待授权标为配对恢复通过。本次等待已随联调应用退出而结束，未替用户操作授权。

## 当前边界与后续验收

- Windows Credential Manager 适配和构建、物理 iOS/Android 设备、Windows 防火墙、多网卡切换、休眠恢复及目标 WebView 高频吞吐仍待实测。已有本机结果不替代这些验收。
- Bonjour/mDNS：隔离 Rust 原生监听使用内存凭据，macOS `dns-sd -B` 已发现 `_peek._tcp.local.`，`dns-sd -L` 正确解析服务端口、`protocolVersion=1` 与 server identity。官方 Flutter 原生示例此次未显示发现结果，因此只将服务发布/系统解析标为通过，官方自动发现仍待排查验证。手动地址连接已有实际闭环。
- 隔离原生发现复现：`cargo run --locked --manifest-path src-tauri/Cargo.toml --example remote_fixture`，终端显示一次性合成配对码与临时端口；该程序不读取系统凭据，按 Enter 停止。示例的“发现局域网桌面”使用官方 `remote.discover()`，没有替代或伪造发现结果。
- Rust 内存 ACK、SDK 待发队列及保留窗口均有硬上限；桌面退出不持久保存诊断。SDK 不额外保留已经 ACK 的历史，桌面丢失内存后通过 gap 显示不可重放范围。
- 诊断每运行最多 16 个 emitter、最近 64 个 gap 范围；累计缺口和淘汰计数不会因窗口淘汰归零。身份、run 与网络关联不得在重连时改变。
- `.peek` 只保存网络，远端正文需先取回。网络/日志完整归档、磁盘恢复属于 P3；当前日志/异常仅提供基础独立列表、筛选、原文/属性与堆栈查看，时间线、异常分组和完整键盘操作属于 P2。
- SDK 只订阅现有 Talker，不捕获 print、原生崩溃或覆盖全局异常入口；编译期禁用必须由接入 App 保证。自由文本脱敏由 App 提供，示例只使用合成数据。
- Vite 的大 chunk 提示和 Flutter 上游插件编译提示仍存在；构建实际成功，不把这些提示或本机 debug 结果等同于发布验收。
