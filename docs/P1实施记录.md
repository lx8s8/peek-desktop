## 实现约定

- 监听默认关闭，由用户显式启动；支持仅本机与局域网模式，手动地址始终可用，mDNS 可选。
- macOS Keychain / Windows Credential Manager 保存稳定 server identity 与设备 token 的 SHA-256 摘要；普通配置和 UI 不接触长 token。凭据失败不降级为明文或临时授权。
- P1 最多配对 4 个设备，以控制系统凭据条目大小。网络授权和诊断授权分别保存；关闭诊断授权仅断开诊断连接，忘记设备关闭两路。
- 配对码只在可信桌面 UI 展示，网络端在握手中接收；不把 token 放入 URL、能力探测或日志。
- ACK 只确认 Rust 内存会话接纳，不表示磁盘写入；完整持久恢复和 `.peekbundle` 仍属于后续阶段。
