# Peek Desktop 0.4.0

全面升级网络排查、软清屏磁盘冷存储、JSON 搜索与局部全选、列表多列排序自定义列宽，以及 POST/HTTP 一键重发与批量并发重放能力。

## 本次发布

- **网络列表软清屏与磁盘溢出冷存储**：
  - 新增「清屏（`⌘/Ctrl+L`）」功能，隐藏当前已有请求但保留底层完整数据，支持随时在「查看历史」与「回到清屏视图」之间无损切换，切回查看时清屏前记录自动淡显区分；
  - 新增实时会话本地临时磁盘冷存储（最多溢出 50,000 条 / 256 MiB，应用退出自动清理），突破热内存 8 MiB 容量上限；溢出历史依然可搜索、查看正文与重发，实时底栏显示冷存数量/体积与热缓存水位，且已固定（Pin）请求在触顶淘汰时优先受保护。
- **跨请求正文全文检索与多维快捷筛选**：
  - 网络搜索框新增「正文」开关，可跨热区与冷存储全部请求检索请求头、请求体与响应体内容；
  - 新增 HTTP 方法（GET/POST/PUT/PATCH/DELETE/OPTIONS/HEAD）与状态码段（2xx/3xx/4xx/5xx/网络失败）下拉筛选及一键重置。
- **多列排序、列宽拖拽与微型耗时瀑布条**：
  - 耗时、大小、时间三列支持三态排序（降序 / 升序 / 恢复默认采集顺序），空值统一排在末尾；
  - 列表新增微型「耗时分布」瀑布条列与可选「来源」列，支持列头拖拽自定义列宽（双击复原）与右上角列显隐配置并本地持久化。
- **POST/HTTP 重放增强与批量重复重发**：
  - 修复 Form 表单 POST 重发时误发内部 JSON 结构的问题，自动还原为标准 `application/x-www-form-urlencoded`；重放弹窗新增请求体 JSON 格式化、`⌘/Ctrl+Enter` 发送、测试环境忽略自签名证书开关，以及响应正文 / 响应头 / 与原响应 Diff 对比三视图；
  - 列表右键新增「原样重发一次」（后台一键重发并在顶栏提供「查看响应」快捷入口）和「批量重复重发…」（支持 1~50 次、1~10 并发受控压测，输出状态分布、Min/P50/P95/Max 耗时及逐次响应详情下钻）。
- **JSON 搜索防错色与 `⌘/Ctrl+A` 局部全选**：
  - 将 JSON 语法高亮与搜索命中改为「先词法分词、再双指针归并」，彻底修复搜索匹配导致下方整段 JSON 全变色的问题；
  - 工具栏、菜单与侧边栏等操作区禁止误选，`⌘/Ctrl+A` 仅全选当前聚焦的正文/JSON/堆栈/输入框范围，不再波及应用外围控件。

开放插件接入规范见 [堆栈还原插件协议](https://github.com/lx8s8/peek-desktop/blob/v0.4.0/docs/堆栈还原插件协议.md)，Flutter 接入见 [peek-flutter-sdk](https://github.com/lx8s8/peek-flutter-sdk)。

## 下载与安装

| 系统 | 安装包 |
| --- | --- |
| macOS 11+，Apple Silicon | `Peek-Desktop_0.4.0_macos-arm64-unsigned.dmg` |
| macOS 11+，Intel | `Peek-Desktop_0.4.0_macos-x64-unsigned.dmg` |
| Windows x64 | `Peek-Desktop_0.4.0_windows-x64-unsigned.exe` |

macOS 挂载 DMG 后拖入 Applications；Windows 运行安装器，默认安装到当前用户目录。

本版本不使用分发证书：macOS 为 ad-hoc 签名、未公证；Windows 未签名，首次运行可能出现系统拦截或未知发布者提示。macOS 可参考 [Apple 的打开应用说明](https://support.apple.com/zh-cn/102445) 或在终端执行 `xattr -cr "/Applications/Peek Desktop.app"` 后打开。

附件 `SHA256SUMS.txt` 可用于核对安装包；三个 `manifest-*.json` 记录源码、平台及构建状态。

## 升级说明

在「关于 Peek Desktop」中点击「检查更新」，下载新版后替换应用或运行安装器即可升级；安装目录之外的配对凭据、设备备注、插件配置与恢复数据继续保留。
