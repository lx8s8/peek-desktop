# Peek Desktop 0.1.0

首个正式版本。用于查看 Flutter App 已采集的网络请求、日志和异常，也支持离线排查。

## 本次发布

- 查看请求和响应 Headers、正文、耗时与状态；JSON 无损格式化、树视图和正文搜索
- 预览 PNG、JPEG、GIF、WebP 图片，可切换原始尺寸、适应窗口或 Hex
- 局域网设备配对、实际 IP 展示、扫码连接和可选 Bonjour 发现
- 同步 Talker 日志与异常，在时间线中跳转关联请求
- 保存 `.peek`、完整 `.peekbundle` 归档，导出 HAR、JSONL、文本和 cURL
- 可选工作区快照与重启恢复，中英文菜单、深浅主题
- 关于页面包含项目与反馈地址、MIT 和第三方声明，可检查 GitHub 正式版本

Flutter 接入见 [peek-flutter-sdk](https://github.com/lx8s8/peek-flutter-sdk)。

## 下载与安装

| 系统 | 安装包 |
| --- | --- |
| macOS 11+，Apple Silicon | `Peek-Desktop_0.1.0_macos-arm64-unsigned.dmg` |
| macOS 11+，Intel | `Peek-Desktop_0.1.0_macos-x64-unsigned.dmg` |
| Windows x64 | `Peek-Desktop_0.1.0_windows-x64-unsigned.exe` |

macOS 挂载 DMG 后拖入 Applications；Windows 运行安装器，默认安装到当前用户目录。

本版本不使用分发证书：macOS 为 ad-hoc 签名、未公证；Windows 未签名，首次运行可能出现系统拦截或未知发布者提示。macOS 可参考 [Apple 的打开应用说明](https://support.apple.com/zh-cn/102445)。

附件 `SHA256SUMS.txt` 可用于核对安装包；三个 `manifest-*.json` 记录源码、平台及构建状态。

## 升级与验证范围

在“关于 Peek Desktop”中点击“检查更新”，发现新版后下载并手动安装。替换应用或运行较新安装器即可升级；安装目录之外的配对和恢复数据继续保留。

三个平台均验证构建和安装包。macOS arm64 完成原生界面、会话打开、正文、导出与恢复验证；Windows 实体机、真实手机相机扫码、跨物理电脑切换及复杂网络环境仍在持续验证，见[待办](https://github.com/lx8s8/peek-desktop/blob/v0.1.0/docs/待办.md)。
