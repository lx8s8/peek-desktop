# Peek Desktop 0.3.1

包含 0.2.0、0.3.0 与 0.3.1 累计功能升级：独立「控制台」连续日志流、无损彩色 JSON 树与智能解码、网络排查效率与请求重放工具，以及开放通用的堆栈还原插件体系（支持单地址自动发现与一键/自动还原 Release 混淆堆栈）。

## 本次发布

- **独立「控制台」连续日志流**：按时间顺序融合展示普通日志与拆分后的 `[http-request]` / `[http-response]` / `[http-error]`，支持虚拟滚动双向预加载与 LRU 缓存、过滤/定位双搜索模式、请求↔响应配对跳转、单块折叠、清屏基线与日志流纯文本导出
- **数据预览 2.0 与网络排查升级**：自研零依赖无损彩色 JSON 树（保留大整数精度、支持一键复制值与 JSONPath）、JWT / Unix 时间戳 / URL 编码 / Base64 JSON 智能解码浮层、概览分段耗时瀑布条与重定向链、行内 Pin 固定、域名快筛胶囊、路径屏蔽、双请求 Diff 对比、编辑后请求重放、Dart Dio / Fetch 代码片段导出与窗口文件拖放导入
- **开放堆栈还原插件体系（v1）**：支持本地 `.symbols` 目录（自动解析 ELF GNU Build ID / Mach-O UUID）、只读内网 HTTP 符号服务与本地 CLI 三类 Provider；支持**单地址自动发现（`GET /manifest` / `/.well-known/peek-plugin.json`）**、拖放 `.peekplugin.json`、`peek-desktop://plugin?...` 一键安装链接与目录自动发现
- **快捷错误堆栈还原**：控制台异常块常驻「还原堆栈」按钮直达详情，异常页支持「自动还原」持久化开关、构建溯源摘要以及「已还原 / 原始堆栈 / 并排对比」双栏视图

开放插件接入规范见 [堆栈还原插件协议](https://github.com/lx8s8/peek-desktop/blob/v0.3.1/docs/堆栈还原插件协议.md)，Flutter 接入见 [peek-flutter-sdk](https://github.com/lx8s8/peek-flutter-sdk)。

## 下载与安装

| 系统 | 安装包 |
| --- | --- |
| macOS 11+，Apple Silicon | `Peek-Desktop_0.3.1_macos-arm64-unsigned.dmg` |
| macOS 11+，Intel | `Peek-Desktop_0.3.1_macos-x64-unsigned.dmg` |
| Windows x64 | `Peek-Desktop_0.3.1_windows-x64-unsigned.exe` |

macOS 挂载 DMG 后拖入 Applications；Windows 运行安装器，默认安装到当前用户目录。

本版本不使用分发证书：macOS 为 ad-hoc 签名、未公证；Windows 未签名，首次运行可能出现系统拦截或未知发布者提示。macOS 可参考 [Apple 的打开应用说明](https://support.apple.com/zh-cn/102445) 或在终端执行 `xattr -cr "/Applications/Peek Desktop.app"` 后打开。

附件 `SHA256SUMS.txt` 可用于核对安装包；三个 `manifest-*.json` 记录源码、平台及构建状态。

## 升级说明

在「关于 Peek Desktop」中点击「检查更新」，下载新版后替换应用或运行安装器即可升级；安装目录之外的配对凭据、插件配置与恢复数据继续保留。
