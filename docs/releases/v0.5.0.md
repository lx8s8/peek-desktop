# Peek Desktop 0.5.0

全面升级多设备运行聚合管理、跨会话对比分析、业务异常识别、接口聚合统计、GraphQL/SSE 协议解析与全局命令面板体验。

## 本次发布

- **同设备历次运行聚合与自动清理**：
  - 侧边栏「实时设备」按 `deviceId` 自动整合同一设备的历次重启/重连运行，支持标注启动时间、多运行折叠展开、重连自动切换至最新在线运行，以及一键清理单台设备的离线历史运行；
  - 实时会话与诊断运行达到容量上限（8 条）时，自动按 LRU 回收最旧的离线运行及其关联离线诊断，避免阻塞新设备接入。
- **跨运行 / 跨设备 Diff 与排查效率升级**：
  - Diff 对比基准提升为工作区全局状态，支持在不同运行或不同设备间对比请求与响应差异，并展示来源设备与运行时间标签；
  - 新增 HTTP 200 响应 JSON 业务错误码识别、全局与按设备持久化降噪规则（跨重连持续生效）、自定义筛选预设弹窗及「慢 ≥1s」快捷过滤；
  - 请求详情、右键菜单及异常详情新增一键复制脱敏 Markdown「排查报告」（自动脱敏 `Authorization`、`Cookie`、`X-Api-Key` 等敏感头，异常报告优先附带已还原堆栈）。
- **接口聚合统计、协议解析与导出增强**：
  - 新增「接口统计」聚合面板，自动归一化路径 ID/UUID/长 Hex 与 GraphQL Operation，统计重复调用、报错、业务异常、Avg/P50/P95 耗时与总流量，并可一键回筛列表或定位样本请求；
  - 自动提取展示 GraphQL `operationName` 徽标；响应预览新增 `text/event-stream` SSE 事件流分块解析与搜索视图；
  - 导出 `.peek` / `.peekbundle` 自动合并磁盘溢出冷存储历史；在线会话支持一键并发补拉未加载的远端小正文；
  - 记住上次监听地址/端口配置，新增可选的「启动应用时自动开始监听」。
- **全局命令面板与首包优化**：
  - 新增 `⌘/Ctrl+P` 全局快捷命令面板，支持快速切换设备/运行、视图、接口统计、规则弹窗与常用动作；
  - 全部非首屏弹窗改为按需懒加载并启用 Vite 8 Rolldown vendor 拆包，显著降低冷启动首包加载体积。

开放插件接入规范见 [堆栈还原插件协议](https://github.com/lx8s8/peek-desktop/blob/v0.5.0/docs/堆栈还原插件协议.md)，Flutter 接入见 [peek-flutter-sdk](https://github.com/lx8s8/peek-flutter-sdk)。

## 下载与安装

| 系统 | 安装包 | 应用内更新产物 |
| --- | --- | --- |
| macOS 11+，Apple Silicon | `Peek-Desktop_0.5.0_macos-arm64-unsigned.dmg` | `Peek-Desktop_0.5.0_macos-arm64-unsigned.app.tar.gz` |
| macOS 11+，Intel | `Peek-Desktop_0.5.0_macos-x64-unsigned.dmg` | `Peek-Desktop_0.5.0_macos-x64-unsigned.app.tar.gz` |
| Windows x64 | `Peek-Desktop_0.5.0_windows-x64-unsigned.exe` | 与安装包复用同一 NSIS 安装器 |

macOS 挂载 DMG 后拖入 Applications；Windows 运行安装器，默认安装到当前用户目录。

本版本不使用分发证书：macOS 为 ad-hoc 签名、未公证；Windows 未签名，首次运行可能出现系统拦截或未知发布者提示。macOS 可参考 [Apple 的打开应用说明](https://support.apple.com/zh-cn/102445) 或在终端执行 `xattr -cr "/Applications/Peek Desktop.app"` 后打开。

附件 `latest.json` 供应用内自动更新读取与验签；`SHA256SUMS.txt` 可用于核对全部安装包与更新归档；三个 `manifest-*.json` 记录源码、平台及构建状态。

## 升级说明

**从 0.4.2 升级至 0.5.0** 可直接在「关于 Peek Desktop」中点击「检查更新 → 下载并安装，完成后重启」完成自动更新；**从 0.4.1 或更早版本升级**需手动下载并替换安装一次。安装目录之外的配对凭据、设备备注、插件配置、降噪/业务错误规则与恢复数据均会自动保留。
