# Peek Desktop 0.4.2

集成桌面应用内更新能力，支持在「关于 Peek Desktop」中直接下载、校验签名、覆盖安装并自动重启。

## 本次发布

- **桌面应用内自动更新**：
  - 集成 Tauri 官方 `tauri-plugin-updater` 插件，内置项目专用 Minisign 公钥并强制校验签名内绑定的版本号（`requireSignedVersion: true`）；
  - 检查更新检测到新版本且存在受信任的 `latest.json` 更新清单时，可直接点击「下载并安装，完成后重启」，实时展示下载进度百分比与字节大小，并在下载阶段支持随时取消；
  - 进入安装阶段前自动保存当前工作区恢复快照并停止远端监听，避免数据丢失或端口占用，安装完成后自动重启；
  - 保留旧版发布兼容与安装失败兜底机制，未提供清单或安装失败时仍可一键打开下载链接与更新说明页；
  - 同步改造三平台打包与发布流程，正式标签发布自动校验更新包 Minisign 签名并生成 `latest.json`。

开放插件接入规范见 [堆栈还原插件协议](https://github.com/lx8s8/peek-desktop/blob/v0.4.2/docs/堆栈还原插件协议.md)，Flutter 接入见 [peek-flutter-sdk](https://github.com/lx8s8/peek-flutter-sdk)。

## 下载与安装

| 系统 | 安装包 | 应用内更新产物 |
| --- | --- | --- |
| macOS 11+，Apple Silicon | `Peek-Desktop_0.4.2_macos-arm64-unsigned.dmg` | `Peek-Desktop_0.4.2_macos-arm64-unsigned.app.tar.gz` |
| macOS 11+，Intel | `Peek-Desktop_0.4.2_macos-x64-unsigned.dmg` | `Peek-Desktop_0.4.2_macos-x64-unsigned.app.tar.gz` |
| Windows x64 | `Peek-Desktop_0.4.2_windows-x64-unsigned.exe` | 与安装包复用同一 NSIS 安装器 |

macOS 挂载 DMG 后拖入 Applications；Windows 运行安装器，默认安装到当前用户目录。

本版本不使用分发证书：macOS 为 ad-hoc 签名、未公证；Windows 未签名，首次运行可能出现系统拦截或未知发布者提示。macOS 可参考 [Apple 的打开应用说明](https://support.apple.com/zh-cn/102445) 或在终端执行 `xattr -cr "/Applications/Peek Desktop.app"` 后打开。

附件 `latest.json` 供应用内自动更新读取与验签；`SHA256SUMS.txt` 可用于核对全部安装包与更新归档；三个 `manifest-*.json` 记录源码、平台及构建状态。

## 升级说明

**从 0.4.1 或更早版本升级至 0.4.2** 仍需手动下载并替换安装一次；安装 0.4.2 后，后续新版本即可在「关于 Peek Desktop」中点击「检查更新 -> 下载并安装，完成后重启」直接完成升级。安装目录之外的配对凭据、设备备注、插件配置与恢复数据继续保留。
