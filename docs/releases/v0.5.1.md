# Peek Desktop 0.5.1

聚焦日常高频使用体验打磨：新增启动自动检测更新提示、Windows 默认覆盖安装与自动关进程、彻底消除 macOS 钥匙串反复弹窗、放宽配对设备上限至 16 台，并精简日志页面顶部空间占用。

## 本次发布

- **启动自动检测更新提示**：
  - 桌面端启动后静默检测新版本并每 6 小时定时复查（离线或限流保持静默），检测到新版本时在顶部展示可一键「查看并更新」或「忽略此版本」的轻量提示条，并在工具栏「关于」图标叠加红点提醒；
  - 「关于 Peek Desktop」中新增「启动时自动检查更新」持久化开关，点击横幅后直接复用预检结果，无需重复等待即可下载安装并自动重启。
- **Windows 默认覆盖安装与自动关闭旧进程**：
  - 定制 NSIS 安装模板与安装/卸载前置钩子：升级旧版时默认跳过卸载确认页直接覆盖原安装目录，安装或卸载前自动关闭正在运行的 `peek-desktop.exe` 及子进程并等待文件锁释放，显著提升手动覆盖安装与应用内更新成功率；
  - 支持简体中文 / 英文安装界面自动匹配，并在 Windows CI 验收中补充同目录二次覆盖安装校验。
- **消除 macOS 钥匙串反复弹窗 & 最大配对设备数放宽至 16 台**：
  - 配对注册表（仅存 `server_id`、设备名与 Token 的单向 SHA-256 哈希，不含明文 Token）改为受当前用户权限保护（macOS 目录 `0o700` / 文件 `0o600`）的原子本地文件存储，彻底消除 macOS 无证书 ad-hoc 签名每次更新或重启监听反复弹出钥匙串密码框的问题；Windows 首次升级自动从旧系统凭据库静默迁移，已配对设备不丢失；
  - 突破原 Windows 单条凭据 2560 字节 UTF-16 上限，将最大配对设备数从 **4 台提升至 16 台**；设备连接弹窗新增实时配额展示（`n / 16`）、弹窗内醒目满额告警与「去清理设备」一键定位高亮。
- **日志 / 异常页面顶部布局瘦身**：
  - 参考控制台将顶部筛选与批量操作重构为紧凑 2 行，高级筛选默认折叠按需展开；对齐控制台的「暂停跟随 / 跟随最新」激活样式并在暂停跟随时提供列表右下角悬浮「回到最新」按钮，大幅增加日志可视面积。

开放插件接入规范见 [堆栈还原插件协议](https://github.com/lx8s8/peek-desktop/blob/v0.5.1/docs/堆栈还原插件协议.md)，Flutter 接入见 [peek-flutter-sdk](https://github.com/lx8s8/peek-flutter-sdk)。

## 下载与安装

| 系统 | 安装包 | 应用内更新产物 |
| --- | --- | --- |
| macOS 11+，Apple Silicon | `Peek-Desktop_0.5.1_macos-arm64-unsigned.dmg` | `Peek-Desktop_0.5.1_macos-arm64-unsigned.app.tar.gz` |
| macOS 11+，Intel | `Peek-Desktop_0.5.1_macos-x64-unsigned.dmg` | `Peek-Desktop_0.5.1_macos-x64-unsigned.app.tar.gz` |
| Windows x64 | `Peek-Desktop_0.5.1_windows-x64-unsigned.exe` | 与安装包复用同一 NSIS 安装器 |

macOS 挂载 DMG 后拖入 Applications；Windows 运行安装器，默认覆盖安装到当前用户目录。

本版本不使用分发证书：macOS 为 ad-hoc 签名、未公证；Windows 未签名，首次运行可能出现系统拦截或未知发布者提示。macOS 可参考 [Apple 的打开应用说明](https://support.apple.com/zh-cn/102445) 或在终端执行 `xattr -cr "/Applications/Peek Desktop.app"` 后打开。

附件 `latest.json` 供应用内自动更新读取与验签；`SHA256SUMS.txt` 可用于核对全部安装包与更新归档；三个 `manifest-*.json` 记录源码、平台及构建状态。

## 升级说明

**从 0.4.2 / 0.5.0 升级至 0.5.1** 可直接在「关于 Peek Desktop」中点击「检查更新 → 下载并安装，完成后重启」完成自动更新；**从 0.4.1 或更早版本升级**需手动下载并覆盖安装一次。升级至 0.5.1 后，macOS 因切换至本地受限配对存储仅需重新配对一次设备，此后跨版本更新均自动保留且永久不再弹出钥匙串密码框；Windows 已有配对设备将自动无感迁移保留。
