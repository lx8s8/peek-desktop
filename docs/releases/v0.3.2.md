# Peek Desktop 0.3.2

多测试机管理与小屏操作体验升级：支持设备自定义备注与重连改名同步，彻底修复请求重发、双请求对比等弹窗在笔记本小屏被分栏裁切或空间过小的问题。

## 本次发布

- **设备识别与自定义备注**：
  - 已配对设备在 App 端切换为真实机型或修改名称重连后，桌面端自动同步刷新设备名称；
  - 桌面端支持按设备 ID 为任意测试机设置本地自定义备注名（侧边栏、当前会话顶栏及已配对列表统一展示备注并保留原上报机型副标）。
- **重发与对比弹窗大窗口体验**：
  - 全部全局弹窗及右键菜单统一通过 React Portal 挂载至顶层 `document.body`，彻底解决被详情/控制台分栏裁切的问题；
  - 请求重发与双请求 Diff 弹窗扩大默认可视尺寸并新增右上角「全屏展开 / 还原」切换，笔记本窄屏（≤ 960px）自动切为「请求编辑 / 响应结果」满宽双 Tab；
  - 网络列表右键菜单新增「重发请求…」直达入口，详情页顶栏快捷按钮支持自动折行防止小屏挤压。
- **堆栈识别兼容性**：前端 AOT 混淆堆栈检测补充支持 Flutter 3.47+ `_kDartSnapshotText`。

开放插件接入规范见 [堆栈还原插件协议](https://github.com/lx8s8/peek-desktop/blob/v0.3.2/docs/堆栈还原插件协议.md)，Flutter 接入见 [peek-flutter-sdk](https://github.com/lx8s8/peek-flutter-sdk)。

## 下载与安装

| 系统 | 安装包 |
| --- | --- |
| macOS 11+，Apple Silicon | `Peek-Desktop_0.3.2_macos-arm64-unsigned.dmg` |
| macOS 11+，Intel | `Peek-Desktop_0.3.2_macos-x64-unsigned.dmg` |
| Windows x64 | `Peek-Desktop_0.3.2_windows-x64-unsigned.exe` |

macOS 挂载 DMG 后拖入 Applications；Windows 运行安装器，默认安装到当前用户目录。

本版本不使用分发证书：macOS 为 ad-hoc 签名、未公证；Windows 未签名，首次运行可能出现系统拦截或未知发布者提示。macOS 可参考 [Apple 的打开应用说明](https://support.apple.com/zh-cn/102445) 或在终端执行 `xattr -cr "/Applications/Peek Desktop.app"` 后打开。

附件 `SHA256SUMS.txt` 可用于核对安装包；三个 `manifest-*.json` 记录源码、平台及构建状态。

## 升级说明

在「关于 Peek Desktop」中点击「检查更新」，下载新版后替换应用或运行安装器即可升级；安装目录之外的配对凭据、设备备注、插件配置与恢复数据继续保留。
