# Peek Desktop 0.4.1

修复网络列表清屏后持续闪烁并在「已清屏」与「加载中」之间反复切换的问题。

## 本次发布

- **修复清屏闪烁与循环重查**：
  - 将 `RequestTable` 查询副作用中的回调依赖（`onMeta` / `onHosts` / `onCount` / `onError`）改由 Ref 托管，彻底消除父组件状态更新触发的无限重查询循环；
  - 同会话内的清屏与实时推送刷新改为静默更新，仅在首次加载会话或显式重试时展示「加载中」，消除空态闪烁；
  - 元数据状态更新增加浅相等去重，降低无效重渲染并补充清屏防循环回归测试。

开放插件接入规范见 [堆栈还原插件协议](https://github.com/lx8s8/peek-desktop/blob/v0.4.1/docs/堆栈还原插件协议.md)，Flutter 接入见 [peek-flutter-sdk](https://github.com/lx8s8/peek-flutter-sdk)。

## 下载与安装

| 系统 | 安装包 |
| --- | --- |
| macOS 11+，Apple Silicon | `Peek-Desktop_0.4.1_macos-arm64-unsigned.dmg` |
| macOS 11+，Intel | `Peek-Desktop_0.4.1_macos-x64-unsigned.dmg` |
| Windows x64 | `Peek-Desktop_0.4.1_windows-x64-unsigned.exe` |

macOS 挂载 DMG 后拖入 Applications；Windows 运行安装器，默认安装到当前用户目录。

本版本不使用分发证书：macOS 为 ad-hoc 签名、未公证；Windows 未签名，首次运行可能出现系统拦截或未知发布者提示。macOS 可参考 [Apple 的打开应用说明](https://support.apple.com/zh-cn/102445) 或在终端执行 `xattr -cr "/Applications/Peek Desktop.app"` 后打开。

附件 `SHA256SUMS.txt` 可用于核对安装包；三个 `manifest-*.json` 记录源码、平台及构建状态。

## 升级说明

在「关于 Peek Desktop」中点击「检查更新」，下载新版后替换应用或运行安装器即可升级；安装目录之外的配对凭据、设备备注、插件配置与恢复数据继续保留。
