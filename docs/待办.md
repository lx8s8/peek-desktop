## 性能验收目标

以下沿用初版目标，尚未在双平台 Release 窗口中完成测量：

| 场景 | 目标 |
| --- | --- |
| 空工作区冷启动 | 进程启动到可交互不超过 2 秒 |
| 普通详情切换 | 元信息展示 P95 不超过 100 ms，远端正文另计 |
| 十万条列表滚动 | 接近 60 FPS，P95 主线程任务尽量低于 16.7 ms |
| 持续输入 | 1,000 条元信息/秒、持续 60 秒，仍可选择与搜索，并核对接收、队列和丢失数 |
| 十万条搜索 | 热索引 P95 不超过 200 ms，不含输入 debounce |
| 1 MiB JSON | 300 ms 内出现可操作的初始视图，不要求全展开 |

输入覆盖 1 万/10 万条、宽对象、深嵌套、大数组、长字符串、无效 JSON、长整数和截断正文；1/10/50 MiB 正文同时检查预览限制及超限拒绝。记录消息/秒、字节/秒、Rust/WebView/总内存与 P50/P95，注明硬件、系统、WebView 和构建模式。已有核心探针结果见 [P0](实施进度.md#单次核心探针) 和 [P3](P3实施记录.md#单次大数据探针)。
