# 堆栈还原插件协议（Symbolicator Plugin Protocol v1）

Peek Desktop 提供完全开放、无厂商耦合的堆栈还原扩展机制，用于将 Release / 混淆打包产物上报的 AOT 地址堆栈（例如 Flutter `--obfuscate --split-debug-info` 产出的堆栈）在桌面端一键还原为源码文件路径与行号。

## 支持的三类 Provider

1. **`local`（本地符号目录）**：指定本机 `.symbols` 目录或单个 `.symbols` 文件。Peek 会自动解析 ELF GNU Build ID / Mach-O `LC_UUID` 精确匹配符号文件，并调用本机 `flutter symbolize` 还原。
2. **`http`（远端 HTTP 符号化服务）**：向任意受控内网 HTTP 服务 POST 标准 JSON 请求并接收还原结果，适合团队共享与测试人员零环境接入（符号文件不离开服务器、无需分发 SSH 私钥）。
3. **`cli`（本地外部 CLI 插件）**：通过标准 `stdin` / `stdout` JSON 协议调用本机脚本或二进制工具，方便与现有内部构建系统或 SSH 远端构建机无缝集成。

## 标准 `.peekplugin.json` 清单格式

```json
{
  "schemaVersion": 1,
  "id": "team-symbolicator",
  "name": "测试环境符号还原服务",
  "description": "连接内网只读符号化服务还原 Release 混淆堆栈",
  "enabled": true,
  "kind": "http",
  "timeoutMs": 20000,
  "http": {
    "endpoint": "http://symbols.internal:17890/v1/symbolize",
    "healthEndpoint": "http://symbols.internal:17890/health",
    "token": "<可选访问令牌>",
    "headers": {}
  }
}
```

### 快速安装方式

- **单地址自动发现（推荐）**：在「插件 → 快速导入」输入服务根地址（如 `http://192.168.x.x:17890` + 可选 Token，或带 `?token=...` 的地址），Peek 会自动探测 `GET /manifest` 或 `GET /.well-known/peek-plugin.json`，一次性拉取完整插件配置与服务端已索引构建摘要并确认安装。
- **文件拖放**：将 `.peekplugin.json`（或 `.peekplugin`）文件直接拖入 Peek Desktop 主窗口，在安装确认框核对信息后点击「确认安装」。
- **一键安装链接**：使用 `peek-desktop://plugin?v=1&data=<base64url>`，在「插件 → 快速导入」中粘贴即可预览安装。
- **目录自动发现**：将 `.peekplugin.json` 放入 `~/.peek-desktop/plugins/`（Windows 为 `%USERPROFILE%\.peek-desktop\plugins\`），重启或打开插件弹窗即可自动识别。

## HTTP / CLI 统一请求与响应契约

### 还原请求（HTTP POST Body / CLI stdin）

```json
{
  "action": "symbolicate",
  "schemaVersion": 1,
  "stackTrace": "build_id: 'a1b2c3...'\n#00 abs ...",
  "stackFormat": "dart",
  "buildId": "a1b2c3...",
  "platform": "ios",
  "arch": "arm64",
  "appVersion": "6.2.19",
  "buildNumber": "60384",
  "flavor": "dev",
  "brand": "demo",
  "jobId": "build_20261123_01",
  "attributes": {}
}
```

### 还原响应（HTTP 200 Body / CLI stdout）

```json
{
  "ok": true,
  "symbolizedStack": "#0 LoginPage.submit (package:app/login.dart:42:9)\n...",
  "matchedBuild": {
    "jobId": "build_20261123_01",
    "appVersion": "6.2.19+60384",
    "flavor": "dev",
    "target": "ipa",
    "sourceSha": "abc1234",
    "sourceBranch": "main",
    "matchedBy": "buildId",
    "symbolFile": "app.ios-arm64.symbols"
  },
  "warnings": []
}
```

### 健康检查（HTTP `GET /health` 或 CLI stdin `{"action":"health","schemaVersion":1}`）

```json
{
  "ok": true,
  "availableBuilds": 12,
  "message": "服务连接正常，已索引 12 个构建符号"
}
```
